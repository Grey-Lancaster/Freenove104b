Freenove104b Touch Tutorial Flasher

Pick a firmware and flash it straight from this page. No software to install.

Your browser can't do this. Web Serial only works in Chrome or Edge on a computer (not phone/tablet, not Safari or Firefox). Open this page in Chrome or Edge and try again.
1

Pick what to flash

Each option is a standalone firmware — flashing one replaces whatever was on the board before.

2

Connect your board

Plug the device into a USB port, then click connect and pick it from the list. This requires the board to be in bootloader mode (it's what actually flashes it) — to just read logs from a board that's already running normally, use View Device Logs below instead, no bootloader mode needed.

3

Flash it

This takes a minute or two. Don't unplug the device or close this tab while it runs.

Aw crap, no port selected

  

    If you didn't select a port because you didn't see your device listed, try
    the following steps:
  

  
    
    
  1. 
      Make sure the device is connected to this computer (the one running the
      browser that shows this page).
    
    2. 
    
  2. Most devices have a tiny light when powered on — make sure it's on.
    3. 
    
  3. 
      Make sure the USB cable you're using can be used for data, not a
      power-only cable.
    
    4. 
    
  4. 
      On Linux, make sure your user is part of the dialout group
      so it has permission to access the device:
      sudo usermod -a -G dialout YourUserName
      You may need to log out and back in (or reboot) for that to take effect.
    
    5. 
    
  5. 
      Make sure you have the right drivers installed. This board uses native
      USB (CDC), so it usually needs no separate driver — but the port
      number will change between bootloader mode and normal running mode,
      which is expected.

      Some boards need the BOOT (or FLASH)

      Again, and release once the log shows "Connected."
    
    2. 
    
  2. 
      Make sure nothing else has the port open — close the Arduino
      Serial Monitor, PlatformIO, or any other browser tab using it.
    
    3. 
    
  3. Try a slower baud rate under Advanced options.
    4. 
    
  4. Unplug the USB cable, plug it back in, and try again.
