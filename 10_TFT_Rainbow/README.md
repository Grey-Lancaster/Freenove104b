# Chapter 10.1 — Raw TFT Drawing

Ported from Freenove's `Sketch_10.1_TFT_Rainbow.ino`. Flashes the screen
through solid red/green/blue/black/white on boot, then repeatedly draws a
shifting rainbow gradient plus a few font-size and float-formatting
samples — all using raw `TFT_eSPI` calls, no LVGL.
