# Chapter 6.1 — SD Card (SD_MMC) Test

Ported from Freenove's `Sketch_06.1_SDMMC_Test.ino`. Exercises the SD
card driver end to end, once, on boot: lists the root directory, creates
and removes a folder, writes/appends/reads/renames a text file, then
prints the card's total and used space — all over serial.
