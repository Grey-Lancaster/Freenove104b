# Chapter 19.1 — Stock LVGL Widgets Demo

Ported from Freenove's `Sketch_19.1_LVGL_Arduino.ino`. Wires up the
standard `TFT_eSPI` + FT6336U touch driver boilerplate for LVGL (per
LVGL's own official Arduino porting guide) and launches LVGL's built-in
`lv_demo_widgets()` showcase — sliders, buttons, charts, tabs, and the
rest of LVGL's stock widget gallery, all interactive via touch.
